## Summary

This NIOSH workbook presents Total Worker Health as an approach that combines protection from work hazards with efforts to advance worker well-being. It explains five defining elements—leadership commitment, safer work design, worker engagement, privacy, and coordinated organizational systems—and provides worksheets for self-assessment and action planning.
